# Airatik2004.github.io

Страница для ссылок «Поделиться» из игры «Судоку» / «Sudoky» (ru.sudoky): `/s/?c=<код>&se=<SE×10>&d=<ключевые ходы>`.

- Ссылка всегда открывается в браузере: поле, уровень, глубина SE, результат друга.
- «Открыть в игре» ведёт в игру по её адресу `sudoky://s/?c=…`; если игры нет — назад на страницу с `noapp=1`.
- Установить: `sudoky.apk` отсюда или RuStore. Язык страницы — по языку браузера, переключатель RU/EN.
