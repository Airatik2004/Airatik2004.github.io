# Airatik2004.github.io

Страница для ссылок «Поделиться» из игры «Судоку» / «Sudoky» (ru.sudoky): `/s/?c=<код>`.

- Игра установлена — Android открывает ссылку в ней (подтверждение: `.well-known/assetlinks.json`).
- Игры нет — страница предлагает установить: `sudoky.apk` отсюда или RuStore. Язык страницы — по языку браузера.
